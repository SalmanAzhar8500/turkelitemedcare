FIRST INSTALL ON WINDOWS / MAMP
1. Start MAMP PRO and MySQL.
2. Open PowerShell in this FINAL folder.
3. Run:
   Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force
4. Run:
   .\INSTALL-WINDOWS.ps1
5. After the installer passes validation, run:
   .\PRESENT-FINAL.ps1

NORMAL LATER START
   .\START-WINDOWS.ps1

The FULL package includes Composer vendor dependencies and prebuilt frontend assets.
Composer/npm installs are not required for the normal Windows/MAMP first launch.
