# FINAL — SEO Plan

## Phase 1

Keep the 100-procedure catalogue for discovery, but concentrate search-engine attention on 20 deep commercial treatment pages.

- 20 priority pages: `index,follow`
- 80 wider catalogue pages: `noindex,follow` until they reach the same editorial standard
- Sample clinic / doctor / patient-story records: `noindex`

## Priority-page requirements

- Unique title and meta description
- Canonical URL
- EN / DE / AR hreflang architecture
- Breadcrumb structured data
- Standalone useful article
- Procedure-specific visual
- Internal links to specialty, related treatments, guides and enquiry
- Provider comparison section
- Medical responsibility disclaimer

## Editorial next wave

Promote additional catalogue pages only after:
1. reviewed, procedure-specific copy exists;
2. useful planning/recovery/provider questions are present;
3. relevant visual exists;
4. medical/editorial review is recorded;
5. the page offers genuine value beyond a keyword variation.
